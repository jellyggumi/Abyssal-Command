# Master GDD Delta — 제품 계약의 변경분

```yaml
run_id: 20260728-onslaught-action-pivot
status: "[TARGET] — 설계 계약. 측정 아님"
owner_skill: build-isometric-arpg
authority: design/master-numeric-contract.md
supersedes: docs/abyssal-command-defense-survivor-design.md (삭제됨 — §0 참조)
scope: 제품 정의, 필러 보존/폐기/신설, 플레이어 루프, 캠페인·성장·연출 델타, 승패 조건
```

이 문서는 **무엇이 바뀌는가**를 제품 수준에서 진술한다. 코드 수준 변경은
`engineering/migration-map.md`가 소유한다. 둘은 독자가 다르다.

---

## 0. 상위 문서 부재 상태 `[OBSERVED]`

이 런 도중 다른 세션이 두 제품 계약 문서를 삭제했다(스테이징됨):

```
D docs/abyssal-command-defense-survivor-design.md
D docs/abyssal-surge-production-cycle.md
```

**따라서 현재 저장소에 "이 게임이 무엇인가"를 진술하는 문서가 없다.** `README.md`는 남아
있으나 디펜스 서바이버 기준으로 작성되어 있어 피벗 후 사실과 어긋난다.

이 델타는 삭제된 문서를 복원하지 않는다. 대신 **피벗 승인 시 새 제품 계약 문서가 무엇을
담아야 하는지**를 규정하며, §9가 갱신 대상 목록이다.

## 1. 제품 정의 델타

| 축 | 이전 | 이후 |
|---|---|---|
| 장르 | 모바일 우선 싱글플레이 **디펜스 서바이버** | 모바일 우선 싱글플레이 **액션 핵앤슬래시 로그라이트** |
| 조작 | 이동만. 전투 자동 | 이동 + 공격 3동사 + 액티브 스킬 |
| 한 판 | 26.9–27.7초 `[OBSERVED]` | 300–480초 `[TARGET]` |
| 실패 조건 | 관문 내구도 0 | 지휘관 생존 실패 |
| 진행 단위 | 스테이지 클리어 | 스테이지 클리어 + **패배해도 누적 성장** |
| 맵 | authored 고정 좌표 | 시드 기반 셀 배치 |
| 서사 전달 | 인게임 텍스트 컷신 | 로비 비디오·연출 이미지 |

**한 문장:** 관문을 지키며 자동 전투를 관전하던 게임에서, **직접 베고 피하며 5–8분을
버티는 게임**으로 바뀐다.

## 2. 필러 — 보존 / 폐기 / 신설

### 2.1 보존 (변경 금지)

| 필러 | 근거 |
|---|---|
| 60 Hz 결정론 시뮬레이션이 권위 | 리플레이·테스트·다이제스트의 기반 |
| 렌더러 단방향 (스냅샷 읽기 전용, `getRunDigest()` 불변) | 동일 |
| 오프라인 로컬 저장 + JSON 내보내기/가져오기 | 계정·클라우드·멀티 없음 |
| 무수익화 — 광고·프리미엄 화폐·가챠·유료 성장·유료 복구 없음 | 제품 경계 |
| 심연 세계관 고유명과 3구역 여정 (`Cinder Span → Abyss Chancel → Echo Throne`) | G1 |
| 3보스 종결 (`Cinder Warden → Veil Tactician → Gate Sovereign`) | G1 |
| `prefers-reduced-motion` 존중, 색 비의존 정보 전달 | G4 |
| **단일 게임플레이 평면** — 시각적 높이는 비보행 장식만 | 이동·타겟팅 판독성 |
| full-bleed 캔버스, 가장자리 HUD | 모바일 계약 |

### 2.2 폐기

| 필러 | 폐기 사유 |
|---|---|
| 자동 기본 공격 | "hit & slash" 요구와 정면 충돌 |
| 관문(gate) 방어 목표 | 플레이어가 움직이며 싸우는 루프와 양립 불가 |
| 6단계 순차 목표 체인 | 페이즈 타임라인이 대체 |
| 3스탠스 편성(`VANGUARD`/`TURRET`/`SPLIT`) | 입력 포화 — 손이 이미 이동+3동사+스킬로 참 |
| 게이트 감쇠 압박(`OBJECTIVE_PRESSURE_*`) | 웨이브 밀도가 압박을 대체 |
| 인게임 텍스트 컷신 릴레이 | 전투 흐름 차단. 로비 미디어로 이전 |

### 2.3 신설

| 필러 | 요구 대응 |
|---|---|
| 콤보 취소가 보상이 되는 근접 전투 | "hit & slash + 역동적" |
| 무적 대시가 콤보를 유지 | "역동적" — 회피가 공격의 연장선 |
| 광역기가 밀도의 답 | "광역스킬과 몬스터 떼로 몰아치는 웨이브" |
| 예고 후 회피 가능한 보스 패턴 | "최종보스의 패턴을 피해가는" |
| 시드 기반 셀 배치 | "pcg 오픈월드 맵 느낌" |
| 세 축이 어긋나게 완주하는 성장 | "지속적으로 성장" |
| 카테고리 제한 + 단계적 해금 스킬 | "제한된 스킬 카테고리", "단계적 사용" |
| 연출이 판독성 위에 얹히는 카메라·VFX | "화려한 연출이 주" |
| 로비 미디어 서사 | "텍스트보다 비디오와 연출된 이미지" |

## 3. 플레이어 루프 (5–8분)

```
출정
 └ DESCENT 30s      강하·정찰    조작 확인, 첫 접촉
 └ SKIRMISH 75s     산개 교전    콤보 학습 · 성장 선택 1
 └ SURGE 75s        밀집 웨이브  광역기 필요성 체감 · 성장 선택 2
 └ MIDBOSS ~60s     중간 보스    패턴 2종 회피 시험 · 성장 선택 3   [처치 전용]
 └ BIGWAVE 60s      빅웨이브     동시 60체 최대 밀도
 └ FINALE ~60s      최종 보스    패턴 5종 + 조합                    [처치 전용]
결과 → Warden XP · Echo Shard · (승리 시) 정예 추출 · 보상 선택
```

| 항목 | 값 |
|---|---|
| 기준 총 길이 | 21600 tick (360초) |
| 허용 밴드 | 18000–28800 tick (300–480초) |
| 하드 실링 | 32400 tick (540초) → 강제 종막 |
| 시간 상한 페이즈 합계 | 14400 tick (고정) |
| 가변분 | `MIDBOSS` + `FINALE` — **보스 페이즈만 총 길이를 늘린다** |

상세: `master-numeric-contract.md#2`, `encounter-wave-spec.md#1`.

### 3.1 순간순간의 루프

```
위협 판독 → 접근/간격 → 콤보(취소로 압축) → 예고 감지 → 대시 회피(콤보 유지) → 재개
                                              └ 광역기로 밀도 정리
```

이 루프가 초당 수 회 돈다. 페이즈 루프(§3)가 분 단위 구조라면 이것은 초 단위 구조다.

## 4. 캠페인 델타

| 항목 | 이전 | 이후 |
|---|---|---|
| 스테이지 수 | 10 | **3 (Cinder Span, Abyss Chancel, Echo Throne)** |
| 순서 | Gate Zenith 종결 | **고정, Echo Throne 종결** |
| 스테이지 해금 | 보스 처치 | **보스 처치** |
| 스테이지 내부 | 웨이브 3슬롯 + 목표 6단계 | 페이즈 6종 |
| 맵 | 스테이지당 authored 1종 | 스테이지당 시드별 변주 |
| 재도전 | 런 스킬 초기화, 순손실 | **XP 40% + Shard 100% 보존** |
| 난이도 램프 | 스테이지별 적 수치 | 적 HP `×(1+0.12(n−1))`, 수 `×(1+0.06(n−1))` |

**재도전 규칙이 캠페인 구조에서 가장 큰 변경이다.** 처치 전용 보스 페이즈에 fail-forward가
없으므로, 패배가 순손실이면 실력 벽이 곧 진행 정지가 된다.

## 5. 성장 델타

| 축 | 이전 | 이후 | 완주 |
|---|---|---|---|
| Warden 스탯 | Echo Core 40, 상한 10 | **+ 레벨당 포인트**, 상한 19 | — |
| Warden Level | 없음 | **신규 1–60** | 95판 |
| 스킬 | 플랫 8종, 레벨 없음 | **20종 / 4카테고리 / L1–5** | 63판 (전체) |
| 로드아웃 | 없음 | **6칸** (2/2/1/1) | 19판 (6칸 L5) |
| 화폐 | Echo Core, Bound Fragment | **+ Echo Shard** (8/스테이지) | — |
| 스킬 트리 | 5노드 | **2노드로 축소** (중복 제거) | — |
| 특성 | 8종, 시퀀스 2/4/6/8/10 | **불변** | — |
| 장비 | 3슬롯 × 5티어 | **불변** | — |
| 런 XP 제안 | 스테이지당 다수 | **3회** | — |
| 리스펙 | 불가 | **스킬·스탯 가능** (Shard 수수료), Echo Core 불가 | — |

**세 축이 19 / 63 / 95판으로 어긋난다** (간격 3.32× → 1.51×, 등비 아님). 목표는 균등
배분이 아니라 동시 종료 회피다. 19판에 로드아웃이 끝난 뒤 shard는 **파워가 아니라
선택지**를 사고, 그때부터 파워 성장은 Warden Level의 스탯 포인트가 떠받친다.
상세: `master-numeric-contract.md#5.2`, `skill-and-growth-spec.md#4.4`.

### 5.1 "사용자 정보에 맞게 지속 성장"의 해석

요구를 세 장치로 번역했다:

1. **패배 보존** — 실력이 부족해도 캐릭터는 강해진다.
2. **세 축 스태거** — 하나가 끝나도 남은 목표가 있다.
3. **카테고리 독립 게이트** — 판 스타일(근접 편중 / 광역 편중)에 따라 다른 스킬이 열린다.

계정 단위 축적이 곧 접근 가능한 선택지의 확장이 된다.

## 7. 승리 / 실패 조건

### 7.1 스테이지 단위

| 결과 | 조건 | 보상 |

- 게임이 재미있다는 것 — 사람 플레이 판정 전까지 미증명.
- 수치가 맞다는 것 — 전부 `[TARGET]`이며 G2 재측정 대상.
- 구현 가능하다는 것 — 렌더러 좌표계 실측(카메라·안개)은 검증했으나 나머지는 미검증.
- 기존 게이트가 유지된다는 것 — G2/G3/G4/G6/G7/G8 전부 재정의 또는 재측정 대상.
