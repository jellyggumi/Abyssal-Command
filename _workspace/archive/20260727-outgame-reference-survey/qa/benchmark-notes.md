## Calibration Takeaways

These benchmarks establish the baseline "game-like outgame" bar Abyssal Surge should meet:

- **A lobby is a loadout theater, not a settings screen.** VS Stage Selection and Soulstone's nav-tab hub prove the bar: the pre-run screen is a composed scene — briefing/modifier stat panel on one side, a scrollable, thumbnailed, *narrated* stage/target list in the center, and one large, unmistakable primary CTA (START). Abyssal's right-dock sortie+briefing should read as this loadout theater, not a form. **This validates the dock direction already taken and sets the polish target.**
- **Every persistent-currency and progression readout is always on screen and always framed.** All five titles keep gold/souls/XP counters visibly docked (framed pills, top corners) rather than buried. Abyssal's warden points, equipment currency, and idle-return rewards should be first-class, permanently-visible framed elements — a reward readout the player passes constantly, feeding the "come back" hook.
- **Upgrade choices earn their space with card theater.** Soulstone's level-up cards (icon + type tags + full stat breakdown + Reroll/Banish/Lock economy) and Doodle's spell cards show the bar: a progression choice is a detailed, illustrated *card* with a mini-economy around it, not a text list. Abyssal's skill-tree nodes, traits, and equipment picks should adopt this card-detail + surrounding-verbs (reroll/lock/banish) treatment to feel like decisions, not menu rows.
- **The metagame tree is a spectacle, not a list.** Soulstone's radial skill tree and Melvor's dense skill rail prove that depth is *shown*: a big, explorable, node-linked map with per-node rank pips (X/5, X/99) reads as "there is a lot of game here." Abyssal's 5-node skill tree and 5-tier equipment currently risk reading as a short list; the benchmark says give them a laid-out, visually-connected, rank-annotated map with a persistent detail tooltip.
- **A grid + detail-tooltip is the standard for collections/unlocks.** VS's Collection and HoloCure's shop both use the icon-grid + selected-item-detail-panel + cost pattern. Abyssal's equipment tiers, extractable companions, and stage-clear traits should use this exact grid-of-icons ↔ detail-panel idiom (with locked/owned states) so unlocking reads as filling a visible set.
- **The strongest outgames make the menu a *place*.** HoloCure's explorable garden hub and Abyssal's own always-visible live 3D canvas point the same way: the outgame should feel spatially inhabited (a stronghold/place the dock floats over) rather than a flat overlay. Abyssal is uniquely positioned here — the live WebGL scene is already the differentiator; the calibration bar is to make the dock panels feel *attached to that world* (framing, depth, motion into/out of the scene) instead of pasted on top.
