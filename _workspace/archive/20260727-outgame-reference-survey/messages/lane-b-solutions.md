# Lane B — Solutions (Browser-Playable Comparables to Abyssal Surge)

Scope reminder: **browser-playable web games first** (HTML5/WebGL, itch.io web, CrazyGames/Poki/Kongregate portals, standalone idle-RPG sites). Native/store-only titles are labeled as **aesthetic/structural reference only**. Every entry carries a source URL + evidence label. Focus is the OUTGAME (lobby/metagame/menu), not in-combat HUD.

Evidence labels used: `direct page retrieval` (I fetched the page), `indexed snippet` (surfaced via search index / third-party wiki), `thin evidence` (weakly corroborated).

---

## Solutions

1. **Grimdark Survivors**
   - What: Wave-survival roguelite ("bullet heaven") — survive an alien horde, pick weapons, fight bosses.
   - Browser-playable? **Yes** — CrazyGames (desktop/mobile/tablet), also Steam. Engine: HTML5.
   - Outgame structure: Pre-run **hero-select + weapon/loadout screen** funnels into a run; each hero = distinct playstyle; run-earned skills/equipment feed a light meta layer. Menu-first, no animated hub.
   - Source: https://www.crazygames.com/game/grimdark-survivors — `direct page retrieval`

2. **Immortal: Dark Slayer**
   - What: Top-down action-survival RPG (Fallen Knight vs. hordes), Souls-flavored, auto-attack combat.
   - Browser-playable? **Yes** — CrazyGames (desktop/mobile/tablet) + App Store (iOS). Engine: Unity 6, portrait.
   - Outgame structure: **"Home base" upgrade menu** — spend gold/gems on permanent stat tracks (Damage/Health/Speed), an inventory/armor screen to equip/upgrade weapon tiers, and a **god/religion passive-select** (Light/Death/Egoism) that persists across runs.
   - Source: https://www.crazygames.com/game/immortal-dark-slayer — `direct page retrieval`

3. **Idle Zombie Wave: Survivors** *(closest structural twin)*
   - What: Idle survival-defense — auto-attacking survivor squad holds the line vs. endless zombie waves + bosses.
   - Browser-playable? **Yes** — CrazyGames (desktop/mobile/tablet), CrazyGames App, App Store, Steam. Engine: Unity 6, portrait.
   - Outgame structure: **Squad-collection + roster management** (25+ unique survivors), an **"Adjutant" system** (equippable modifiers), **200+ equippable items** inventory, upgrade-defenses meta screen, idle/offline accrual. Directly parallels Abyssal Surge's companions + equipment + traits.
   - Source: https://www.crazygames.com/game/idle-zombie-wave — `direct page retrieval`

4. **Autogun Heroes**
   - What: Auto-shooting arcade survivor-platformer; blast alien waves with a squad of unlockable heroes.
   - Browser-playable? **Yes** — CrazyGames (desktop/mobile/tablet) + App Store (iOS/Android). Externally-hosted iframe build.
   - Outgame structure: **"Basecamp" hub** — unlock heroes with credits, **equip items + upgrade gear between levels**, an **"Alien DNA" skill tree**, and a **stage/world progression map** (Galactic Alliance worlds). Explicit run→basecamp→run loop.
   - Source: https://www.crazygames.com/game/autogun-heroes-izk — `direct page retrieval`

5. **Melvor Idle**
   - What: Menu-driven idle/incremental RPG (RuneScape-inspired) — skilling + auto-combat, deep gear tiers.
   - Browser-playable? **Yes** — free web version at melvoridle.com (also Steam/mobile wrappers). Web app (TypeScript/JS SPA).
   - Outgame structure: **Sidebar/top-nav "hub" of functional tabs** (Skills / Combat / Shop / Bank), a **save-slot main menu** as the "lobby," flat list-based navigation to keep clicks-to-action low, full **offline/idle progression** on return. Pure functional-dock model (what Abyssal Surge risks feeling like).
   - Source: https://melvoridle.com/ — `direct page retrieval`

6. **Diep.io**
   - What: Top-down arena tank shooter (.io); farm shapes, level up, fight players.
   - Browser-playable? **Yes** — diep.io (also on CrazyGames). Native browser .io.
   - Outgame structure: No persistent hub — in-run **stat-point allocation (8 stats)** + a **radial/concentric class-evolution tree** (Tier 1→4, hold 'Y' to view). The "menu" is an overlay on the live arena; progression resets per run.
   - Source: https://diep.io/ (mechanics via https://diepio.fandom.com/) — `indexed snippet`

7. **EvoWars.io**
   - What: Top-down battle-arena (.io); collect orbs to evolve your warrior into bigger-weapon forms.
   - Browser-playable? **Yes** — CrazyGames (desktop/mobile/tablet) + App Store/Android. Externally-hosted iframe.
   - Outgame structure: Thin outgame — a **character-model select/unlock** (15+ models, 36 evolutions) and a **mode picker** (Deathmatch/Teams/Duel/Monster Hunt/Classic) precede the run; growth is in-run XP evolution, not persistent metagame.
   - Source: https://www.crazygames.com/game/evowarsio — `direct page retrieval`

8. **Void Idle**
   - What: Browser idle RPG focused on long-term gear chase; auto-combat with party + world bosses.
   - Browser-playable? **Yes** — voididle.com. Browser idle RPG.
   - Outgame structure: Menu-hub with **weapon-specific ability trees**, a **gear-chase system (enhancement / tiers / runes)**, and **party/co-op combat + world bosses**; offline-progression focus. Mirrors Abyssal Surge's skill-tree + 5-tier equipment.
   - Source: https://voididle.com/ (surfaced via r/incremental_games) — `indexed snippet`

9. **Milky Way Idle**
   - What: Browser idle "skilling" RPG (mining/smithing/combat queues) with player economy.
   - Browser-playable? **Yes** — milkywayidle.com. Browser idle RPG.
   - Outgame structure: **Tabbed skill/action hub** where you queue tasks that process offline; central marketplace + inventory management screens; a set-and-forget lobby loop.
   - Source: https://www.milkywayidle.com/ (via GameSpot roundup) — `indexed snippet`

10. **Taming.io**
    - What: Top-down survival .io with **tameable pets/companions** that fight alongside you + base building.
    - Browser-playable? **Yes** — taming.io / CrazyGames. Native browser .io.
    - Outgame structure: In-session growth loop — **pet/companion taming + management**, resource-gather → **base/defense upgrade menu**; the built base is the persistent "hub" within a session. Nearest .io analog to Abyssal Surge's companion/formation idea.
    - Source: https://taming.io/ (mechanics via search) — `indexed snippet`

11. **YORG.io**
    - What: Base-defense .io (tower-defense × .io) — build a base, manage supply chains vs. zombie waves.
    - Browser-playable? **Yes** — yorg.io. Native browser .io.
    - Outgame structure: The **base itself is the persistent hub**; a **build/upgrade menu** for defenses and production is the primary metagame surface; day/night wave escalation drives the loop.
    - Source: https://yorg.io/ (via CrazyGames-adjacent roundup) — `indexed snippet`

12. **G123 idle-RPG platform** (e.g., Queen's Blade / Goblin Slayer titles)
    - What: Platform of browser-native, licensed **idle RPGs** with hero collection, formation, gacha.
    - Browser-playable? **Yes** — g123.jp, instant-play in Chrome/Safari, cross-device sync, no install.
    - Outgame structure: Shared template — a **central hub screen** for team management + shop + idle-reward claim, **hero-collection + team-formation** grids, **gacha/summon** screen, **daily-login bonuses** + daily quests/events driving retention. Textbook gacha-idle outgame (mostly the mobile-idle pattern, running in-browser).
    - Source: https://g123.jp/ — `indexed snippet`

13. **World Survivors / Time Walker: Survive / Limitless Survivor** (roguelite portal cluster)
    - What: Lightweight browser survivor-roguelites — wave survival with build-per-run upgrades (Limitless Survivor leans incremental/infinite-progression).
    - Browser-playable? **Yes** — roguelite.org "Action Survivor" section (World Survivors, Time Walker) and itch.io "Play in browser" tag (Limitless Survivor, Cozy Space Survivors, Neon Survivors).
    - Outgame structure: Minimal — **character/mode select + a single Play button**; upgrades are largely in-run; meta layer is thin-to-none. Represents the "just a menu" baseline Abyssal Surge is trying to exceed.
    - Source: https://roguelite.org/ ; https://itch.io/games/tag-vampire-survivors — `indexed snippet`

### Aesthetic/structural references only (NOT browser-playable)

Aesthetic/structural reference only. Source: https://store.steampowered.com/app/1794680/Vampire_Survivors/ — `thin evidence`
- **AFK Arena / Idle Heroes** (mobile store) — the canonical idle-gacha outgame: animated hub, hero-collection + formation, daily-login theater, "welcome back" idle-reward popup. **Key structural insight for Abyssal Surge:** browser comparables reliably ship patterns 1–8 (play button, upgrade menus, gear inventory, hero select, dock nav, idle claim, skill tree, stage map) — Abyssal Surge already has all of these as its left/right dock. What is **systematically missing** in the browser cohort (pattern 13, animated theatrical hub) is exactly the "juice/game-feel" layer the redesign targets; the closest juice references (AFK Arena / Idle Heroes animated hub, VS-style powerup theater) live in the store-only reference tier, so the redesign is importing native-game outgame theater into a browser dock shell — a relatively uncontested move in the browser space.

## Categories

Games grouped by structural archetype (a game may span two; listed under primary).

- **pure-survivor** (thin/no metagame; run is everything): Grimdark Survivors; World Survivors; Time Walker: Survive; Limitless Survivor / Cozy Space / Neon Survivors (itch.io cluster). *Aesthetic ref: Vampire Survivors.*
- **survivor + RPG-meta** (survivor combat + persistent progression, closest to Abyssal Surge): Immortal: Dark Slayer; Autogun Heroes; Idle Zombie Wave: Survivors.
- **idle-RPG** (offline accrual, skilling/gear, dock-nav hub): Melvor Idle; Milky Way Idle; Void Idle; G123 idle-RPG platform. *Aesthetic ref: AFK Arena / Idle Heroes.*
- **roguelite-hub** (explicit hub/basecamp between runs + character-select/merchant): Autogun Heroes (basecamp); Grimdark Survivors (hero-select hub); + the documented HTML5 "Hub state vs. Run state" architecture pattern (CharacterSelect + UpgradeMerchant + PlayButton, localStorage-persisted).
- **.io-arena** (session-based arena, in-run growth, base or class tree): Diep.io; EvoWars.io; Taming.io (companion/base); YORG.io (base-defense).
